## About Me

개발을 시작했을 당시에는 기능 구현에 집중했지만, 앱 아키텍처와 Hilt, Jetpack Compose를 적용하는 과정에서 개발 효율성과 유지보수성을 고려한 구조의 중요성을 체감하게 되었습니다. 이후에는 단순 구현을 넘어서, 코드 구조와 아키텍처를 함께 고려하는 개발을 지향하고 있습니다.

Kotlin 기반 개발 경험을 바탕으로, 하나의 언어로 Android와 iOS를 함께 개발할 수 있는 Kotlin Multiplatform에 관심을 가지고 있습니다. 로지아이에서 Android와 iOS 앱을 모두 개발한 경험이 있으며, 앞으로는 iOS와 KMP에 대한 이해를 더욱 높이고 실제 프로젝트에 적용할 수 있는 역량을 갖춘 개발자로 성장하고자 합니다.
